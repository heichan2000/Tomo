# Tomo

A mobile project/task manager built around a Pomodoro timer, where completing
focus sessions rewards a virtual pocket pet. Flutter, offline-first, no
first-party backend. See `Tomo_PRD_MVP.md` and `Tomo_Tech_Stack_Architecture.md`.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `heichan2000/Tomo`, managed with the `gh` CLI.
External PRs are **not** a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles use their default label strings
(`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`).
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root.
See `docs/agents/domain.md`.
